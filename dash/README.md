# Forex ML Signal Dashboard

A live, Flask-based visualization dashboard for the `production_predictor.py` system. It displays live signals, active support/resistance zones, daily plans, weekly plans, and derived summary statistics.

> [!NOTE]
> The dashboard reads data directly from the JSON files inside the `signals/` folder generated by the predictor.

---

## 📁 Directory Structure

The dashboard is located in the `dash/` directory at the root of the project:

```text
forex_ml_system/
├── production_predictor.py
├── signals/                      # Live signals outputs
│   ├── all_signals.json          # Source of truth for signals
│   ├── daily_plan.json           # Daily plans
│   ├── weekly_plan.json          # Weekly plans
│   └── zones_*.json              # Active price zones tracker
│
└── dash/                         # Dashboard folder
    ├── server.py                 # Flask server
    ├── index.html                # Main UI interface
    ├── ml_signal_terminal_v8.html# Alternative Terminal UI
    ├── requirements.txt          # Pip requirements
    ├── style.css                 # Local CSS style copy
    └── static/
        ├── css/
        │   └── style.css         # Main stylesheet served by Flask
        └── js/
            └── app.js            # Frontend JavaScript logic
```

---

## 🚀 Setup & Execution

### 1. Install Dependencies
Run from the root of the project with your virtual environment active:
```bash
pip install -r dash/requirements.txt
```
*(Installs `flask` and `flask-cors`)*

### 2. Run the Dashboard Server
Run the Flask server:
```bash
python dash/server.py
```
By default, the server starts on **[http://localhost:5050](http://localhost:5050)**.

---

## 📡 API Endpoints

The Flask server provides the following endpoints for the frontend to query:

| Endpoint | Description |
| :--- | :--- |
| `GET /api/signals` | Retrieves all signals from `all_signals.json` |
| `GET /api/daily_plan` | Retrieves the daily plan from `daily_plan.json` |
| `GET /api/weekly_plan` | Retrieves the weekly plan from `weekly_plan.json` |
| `GET /api/zones` | Automatically merges and returns all `zones_*.json` files found |
| `GET /api/zones_state` | Retrieves active tracker states |
| `GET /api/stats` | Computes live stats (e.g. win rates, average RR) from completed signals |
| `GET /api/health` | Returns server health and files availability status |

---

## 👥 Multi-Pair Support

The dashboard dynamically scans for any zone files matching `zones_*.json` in the `signals/` directory (e.g. EUR/USD, GBP/USD, etc.).
- The `/api/zones` endpoint will auto-discover and load these pairs.
- The UI automatically renders first-discovered pair mapping. To add tabs for switching between pairs, customize `dash/static/js/app.js`.

---

## ⚙️ Run in Background (Production)

To run the Flask dashboard as a background service on a remote server:

```bash
# Start background process
nohup python dash/server.py > dash/server.log 2>&1 &
echo $! > dash/server.pid

# Stop background process
kill $(cat dash/server.pid)
```
